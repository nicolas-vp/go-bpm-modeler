# План

## Сделано

- Каркас: Wails v2, рабочая папка, вкладки, сохранение, панель инструментов, левая панель изменяемой ширины.
- Расширения `gobpm:*`, ограничения палитры и меню замены BPMN под go-bpm.
- Панель свойств `gobpm:*`, русский интерфейс bpmn-js.
- AI task (экспериментально, включён по умолчанию).
- Иконка приложения, обход пустого окна WebKitGTK на NVIDIA.
- Браузерные тесты в репозитории (`make test`), CI со сборкой под четыре платформы.
- Публикация сборок на go-bpm.tech/modeler/ (каналы dev и latest).
- Правила рисования BPMN: граничные события по матрице go-bpm, один исходящий переход у задач и событий, без
  подпроцесса в подпроцессе.
- Линтер BPMN: правила `gobpm/*` (`frontend/src/bpmn/lint/rules.ts`), маркеры на элементах и счётчик проблем.

## Дальше

1. **Ограничения DMN.** Только decision table: без input data, BKM, knowledge source, literal expression и связей;
   hit policy и типы - из спецификации. Линтер DMN: синтаксис ячеек, имена выходов.
2. **Встроенный MCP-сервер.** Моделер поднимает MCP-сервер, через который AI-агент работает с рабочей папкой и
   открытыми диаграммами. Решить:
   - транспорт: Streamable HTTP на `127.0.0.1` (агент подключается к запущенному моделеру) или stdio (моделер
     запускается агентом как процесс);
   - инструменты: список файлов, чтение и запись BPMN/DMN, проверка линтером, правка открытой диаграммы с
     отображением в окне;
   - безопасность: только localhost, токен, доступ только к рабочей папке.
3. Мелочи: список всех проблем линтера с переходом к элементу, заголовок типа в панели свойств (AI task, перевод),
   подсказки `title` в палитре, конвертация `zeebe:*` → `gobpm:*` при открытии, ярлык `.desktop` для Linux, подпись
   бинарников macOS и Windows.

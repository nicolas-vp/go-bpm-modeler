# План

## Сделано

- Каркас: Wails v2, рабочая папка, вкладки, сохранение, панель инструментов, левая панель изменяемой ширины.
- Расширения `gobpm:*`, ограничения палитры и меню замены BPMN под go-bpm.
- Панель свойств `gobpm:*`, русский интерфейс bpmn-js.
- AI task (экспериментально, включён по умолчанию).
- Иконка приложения, обход пустого окна WebKitGTK на NVIDIA.
- Браузерные тесты в репозитории (`make test`), CI со сборкой под четыре платформы.
- Публикация сборок на go-bpm.tech/modeler/ (каналы dev и latest).
- Правила рисования BPMN: граничные события по матрице go-bpm, один исходящий переход у задач и событий, без
  подпроцесса в подпроцессе.
- DMN под go-bpm: палитра и меню DRD без неподдерживаемого (input data — для информации), новое решение с
  таблицей, типы, линтер DMN с подсветкой ячеек.
- Встроенный MCP-сервер: агент читает рабочую папку и открытые схемы (с несохранённым), выделение, проблемы
  линтера; правки и новые файлы — после подтверждения пользователем.
- Линтер BPMN: правила `gobpm/*` (`frontend/src/bpmn/lint/rules.ts`), маркеры на элементах и счётчик проблем.
